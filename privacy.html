2. 접근하는 정보

사용자가 동의한 drive.readonly 권한으로 Drive 파일 이름, 식별자, 파일 형식, 연결 주소 등 메타데이터와 요청한 파일의 내용을 읽을 수 있습니다. Google API 권한 범위는 특정 폴더에만 한정되지 않습니다.

연결 상태 확인 과정에서 Google Drive API가 제공하는 계정 표시 이름을 확인할 수 있습니다. Google 계정 비밀번호는 이 앱에서 수집하지 않습니다.

인증을 위해 OAuth 클라이언트 정보와 갱신 토큰이 필요합니다. 비밀정보는 클라우드 환경에서 제공하는 보안 설정으로 관리하며, 앱 안내 사이트나 공개 Git 저장소에 등록하지 않습니다. 접근 토큰은 요청 처리에 필요한 동안 프로세스 메모리에서 사용합니다.

4. 외부 서비스에서의 처리

Google은 계정 동의·인증과 Drive 원본 자료 제공을 담당합니다. OpenAI Codex는 사용자가 요청한 작업을 수행하기 위해 필요한 자료를 처리합니다. 이 과정에는 해당 서비스의 약관, 개인정보처리방침과 사용 계정의 데이터 설정이 적용됩니다.

GitHub Pages는 이 공개 앱 안내·정책 페이지의 호스팅을 담당합니다. 이 사이트에는 Drive 원본 자료, 비밀정보 또는 개인 작업 기록을 게시하지 않습니다.

Google API로 받은 정보의 사용 및 다른 서비스로의 전달에는 Google API Services User Data Policy와 Limited Use 요구사항을 적용합니다. 실제 연결 운영은 그 요구사항에 맞는 데이터 처리 설정을 전제로 합니다.

5. 보관과 삭제

Drive 원본은 Google Drive에 유지됩니다. 작업에 사용된 내용 일부는 Codex 대화, 작업 파일 또는 사용자가 요청한 산출물로 남을 수 있습니다. 보관 기간과 삭제 방법은 자료가 저장된 서비스 및 사용 계정의 설정에 따릅니다.

전체 Drive의 자동 복제나 별도 영구 색인을 기본으로 생성하지 않습니다. 작업용 다운로드와 임시 파일은 작업 목적에 맞게 관리하고, 사용이 끝나면 해당 작업 환경의 정리 절차에 따라 삭제합니다.

이 방침은 외부 서비스의 모든 기록이 즉시 삭제되거나 보관되지 않는다고 보장하지 않습니다. 관련 자료의 삭제가 필요하면 저장된 서비스에서 직접 삭제하거나 지원 이메일로 문의할 수 있습니다.
